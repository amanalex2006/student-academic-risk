# Local trained-model storage

Run the notebook through its **Save models for the website** section, or run:

```powershell
.\.venv\Scripts\python.exe scripts\train_models.py
```

This folder receives four fitted scikit-learn pipelines (`*.joblib`) and
`manifest.json`, containing measured evaluation results, checksums, training dates,
and package versions. The website loads these files without retraining.

Generated binaries and the manifest are ignored by Git. Keep them together when
moving the application to another computer, and use the same dependency versions.
Only load artifacts generated by this project: joblib files can execute Python
code during loading. The website does not accept model uploads or arbitrary paths.

Re-exporting the notebook replaces the four models and manifest. Restart the web
server afterward to load the new artifacts. No student submissions are saved here.
